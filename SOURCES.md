# Data sources and attribution

No dictionary database or frequency corpus is bundled in this repository. The app retrieves and reformats content on demand.

- **Wiktionary contributors:** English Wiktionary and the target-language editions. Each rendered entry links to the relevant pages, whose history identifies contributors. Text is extracted, shortened and reformatted. Grammar frames restate explicit source labels, collocations come only from named source sections, and cross-language terms come from explicit translation or etymology links. These fields are incomplete when the source entry is incomplete. See the source page footer and [Wikimedia Terms of Use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) for applicable licenses, normally CC BY-SA 4.0 and, where applicable, GFDL. Reused text and derivatives retain their applicable terms.
- **Wikipedia contributors:** optional summaries from the selected language edition. Each summary links to its source article and history. See that article's footer for licensing. No article images are embedded in this release.
- **Tatoeba contributors:** examples and English translations via the public API. Sentence IDs, authors and the API-reported sentence license are linked in the UI and exported cards. A translation's own sentence page governs its license. [Terms of use](https://tatoeba.org/en/terms_of_use).
- **FrequencyWords / OpenSubtitles:** word-form ranks loaded from the 2018 files in [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords), which documents its sources and licenses. The app shows a rank/band rather than reproducing the corpus. These ranks are noisy and not lemma frequencies or CEFR levels.

Contrast mode compares independently sourced entries; it does not generate a verdict about which word is correct. If a source is missing or a field cannot be extracted, this app does not assert that the linguistic information does not exist. Please check the linked source.

## Word structure and family

Morphology reformats explicit plus-sign formation analyses from English Wiktionary. Only same-language linked components in short, unambiguous formulas are accepted. Explicit synchronic/surface analyses are labeled current word structure; other formulas are labeled source-listed formation, not proof of present-day productivity. Historical components, uncertain/alternative analyses and entries with multiple etymologies are omitted. Derived words come only from named Derived terms sections, never Related terms or spelling similarity. Chinese links require explicitly simplified (Hans) source markup; coverage is intentionally sparse. Inflected-form resolution remains separate. Each panel links back to the source entry and its history; text retains applicable Wikimedia ShareAlike terms. No additional service or runtime AI is used.

## Pronunciation recordings

Recordings are discovered only in the selected English Wiktionary language’s pronunciation section, then verified using the official Commons imageinfo/extmetadata API. The UI retains each file’s exact creator, additional attribution/credit, source page, license name and license URL. Metadata HTML is converted to plain text; only validated Commons, Wikimedia media and Creative Commons license URLs are used. Files without verified creator and supported individual licensing are not embedded. Supported licenses in this first pass are CC BY, CC BY-SA, CC0 and public-domain-mark URLs, not a blanket Wikimedia license.

Recordings are played unedited from the official file or official source-listed transcode, with browser-compatible formats and retry. No media preloading, autoplay, synthesis, bundling or re-licensing. Regional labels come only from explicit source labels. Playback is labeled as the displayed lemma/headword; an inflected search is not claimed to have its own recording. Multiple etymologies, multiple pronunciation sections, differing headword/stress forms and unverified Chinese variety associations are conservatively omitted. Missing recordings, unverified attribution and failed requests are distinct states. Up to four recordings are shown, with the source page available for the rest.
